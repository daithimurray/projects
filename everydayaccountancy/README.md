# Everyday Accountancy Services: website

Single-page static site for Everyday Accountancy Services (Galway & Dublin).
Intended URL: https://getawebsite.ie/everydayaccountancy/

One self-contained file (CSS inlined, fonts from Google Fonts). It uses no relative
asset paths, so it works with or without a slash at the end of the URL.

## Before launch (blocking)

1. **Client sign-off**: written OK from EAS to publish on getawebsite.ie.
2. **Team photos**: currently hotlinked from everydayaccountancy.ie. Save local copies
   into this folder and update the three `<img src>` values.
3. **Legal pages**: the Privacy / Terms / Cookies footer links are `#` placeholders.
4. **Enquiry form**: opens a pre-filled email to info@everydayaccountancy.ie. Swap for
   a form service if the client wants submissions without an email app.
