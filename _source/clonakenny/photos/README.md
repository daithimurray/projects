# Photo inbox: Clonakenny Flower Farm

Drop the original photos here (any file names). They are not deployed.
Claude picks the best ones, crops and compresses them into `clonakenny/img/`, and records
where each one came from in `clonakenny/README.md`.

Upload on GitHub: open this folder on the `claude/magical-ride-py1orb` branch, then
**Add file → Upload files**, drag the photos in, and commit straight to the branch.

Rights check before launch:
- Press photos (e.g. files named `*-860902.jpg`, from the Irish Farmers Journal article) belong to
  the paper or its photographer. Use them only with permission, or ask Ali for her own shots.
- Photos showing the children are not published.
