# UI kit: cathyconlon.ie (proposed, single page)

One scrolling page built from the system's components. Open `index.html`. Anchor nav (Books · Swift & Vanessa · Poetry · Events · About · Contact) highlights the section in view; Candlelight switch persists; contact form validates; toasts confirm.

Sections in order: Hero → Books (both, with buy/stockists) → Celbridge 1720 / Swift & Vanessa (inverse band) → Poetry (setting-only PoemBlock + links to published poems + journals) → Events (Upcoming empty state / Past) + News → About (bio, prizes, press kit) → Contact + letter signup.

Content is in `data.js` from `uploads/cathy-conlon-dossier.md`. Verified facts used as-is; reported ones labelled; **no poem text reproduced**. The earlier multi-page screens (`HomeScreen.jsx` etc.) remain as an alternative structure.
