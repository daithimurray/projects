PoemBlock, the reason the site exists. Body-large Newsreader, 30rem measure, hanging indent so wrapped lines never read as new lines.

```jsx
<PoemBlock title="The Light Dancing" meta="from The Light Dancing, Revival Press 2025" endMark
  stanzas={authorSuppliedStanzas} />
```
`authorSuppliedStanzas` is the poem exactly as the author typed it, never paraphrase or reproduce published text without permission.
```jsx
// setting-only specimen for docs
<PoemBlock title="Specimen" stanzas={[["Set each line as the poet set it,","\tlet the long ones hang,","and give the stanza room to breathe before the next one begins."],["None of this is the author's text;","it shows the setting only."]]} />
```
Never justify. Never centre unless the poet's manuscript centres. Line breaks are the author's, do not reflow.
