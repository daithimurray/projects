Alert

Stable

Inline, persistent message tied to a page or form. Tinted background, full-strength text, icon, optional action.

How we price
Guide prices assume ceilings under 2.7m and sound plaster. Your quote is fixed once we’ve seen photos.
Request sent
We’ve emailed a copy to mary@example.com. Expect a reply by Tuesday.
Exterior work paused for weather
Rain forecast all week; we’ll confirm a new start by Friday.
See dates
We couldn’t send your request
Fix the 2 fields below, or call us on 087 875 3433.
  • Eircode: enter a full Eircode
  • Email: include an @

Anatomy

  1. Container 16px pad, radius 8, semantic tint
  2. Icon 20px, semantic text colour
  3. Title 600 + body
  4. Optional action link / dismiss

Usage

  • Info for context, success after submit, warning for schedule, error for form summary.
  • Errors list each field as a link.
  • No left border stripe. The tint is enough.

Accessibility

  • role="alert" for errors (interrupts), role="status" otherwise.
  • Focus moves to the error summary on submit.
  • Text on tints ≥ 7:1 in all four tones.

Spec

<Alert tone="info|success|warning|error"
  title action={{label,href}}
  dismissible>…</Alert>

Toast

Stable

Brief confirmation after an action: “Added to shortlist”, “Photo uploaded”. Bottom-centre on mobile, bottom-left on desktop. Auto-dismisses in 5s.

Added ‘De Nimes’ to your shortlist
Uploading 3 photos…
Couldn’t save. Check your connection.

Anatomy

  1. plaster.900 surface, radius 8, shadow lg
  2. Status icon 18 (tinted), message 14px
  3. Optional ochre.200 action, dismiss ×

Usage

  • One at a time; new replaces old.
  • Never for errors that need fixing — use Alert.
  • Message ≤ 60 characters; one action max.

Accessibility

  • Live region rendered at page load; content swapped in.
  • Timer pauses on hover/focus; toasts with actions persist until dismissed.
  • Not focus-stealing.

Spec

toast({ tone, message, action })
duration 5000 · enter 250ms fade+8px
exit 150ms · bottom 24 (mobile 16)

Modal

Stable

For a decision that must be made now, or a lightbox. Everything else is a page or a Drawer.

Leave without sending?

You’ve added 3 photos and filled in most of the form. We can save it for 7 days and email you a link.

Anatomy

  1. Scrim rgba(26,24,22,0.5)
  2. Panel 480 (sm) / 720 (md) / 90vw (lightbox), radius 12, shadow lg, 32px pad
  3. Title H3 + close
  4. Body, footer buttons right-aligned

Usage

  • Title is a question or verb phrase; the primary button answers it.
  • Destructive primary uses error.500 fill.
  • Below 640px, panels become bottom sheets with radius 12 top only.

Accessibility

  • Native <dialog>; focus trapped, returns to trigger on close.
  • Esc and scrim click close (unless mid-upload).
  • Initial focus on the least destructive button.
  • Background inert, scroll locked.

Spec

<Modal open title size="sm|md|lightbox"
  onClose actions={[…]}>…</Modal>
enter 400ms: scrim fade, panel
scale .98→1 + fade · exit 250ms

Tooltip

Stable

Names an icon button or explains a term (“eggshell”). Never holds anything the user must read to proceed.

Close
Finish: eggshellLow-sheen finish (10–20% gloss). Wipeable, hides brush marks; our default for woodwork.

Anatomy

  1. plaster.900 bubble, radius 6, 6/10 pad (label) or 8/12 (definition)
  2. 13px text, max 240px
  3. 8px offset, no arrow

Usage

  • Label tooltips on every icon-only button.
  • Definition tooltips on dotted-underline terms, max one per paragraph.
  • Touch: definition opens as a small bottom sheet instead.

Accessibility

  • Shows on hover and focus; 300ms delay in, 0 out; Esc dismisses.
  • aria-describedby links trigger to bubble.
  • Stays visible while pointer moves onto it (WCAG 1.4.13).

Spec

<Tooltip label="Close" side="top">
  <IconButton…/>
</Tooltip>
delay 300 · fade 150ms · z 60

Skeleton & progress

Stable

Loading placeholders shaped like the content, plus a linear progress bar for uploads.

{{ skelPhoto }}{{ skelLine1 }}{{ skelLine2 }}
Uploading photos2 of 3
Done✓
{{ spinner }}Checking your Eircode…

Anatomy

  1. Skeleton blocks: plaster.200 → 100 shimmer, radius matches target
  2. Progress track 6px plaster.200, fill ink.800 / success
  3. Spinner 20px, 2px, ink.800

Usage

  • Skeleton for >300ms loads of known layouts (portfolio grid).
  • Spinner for indeterminate <3s checks.
  • Progress bar only when we know the total.

Accessibility

  • Skeleton region aria-busy="true"; announce “Loading projects”.
  • Shimmer off under reduced motion.
  • Progress announces at 25% steps, not every %.

Spec

<Skeleton shape="rect|text|circle"/>
<Progress value={66} label/>
<Spinner size={20}/>
shimmer 1.6s linear infinite

Progress steps

Stable

Shows where you are in the three-step quote flow. Also the “how it works” explainer.

  1. The job
  2. 2Photos
  3. 3Your details
Step 2 of 3 · Photos

Anatomy

  1. Node 32px: done (ink fill + check), current (ink ring + ink.50 halo), upcoming (plaster.200 ring)
  2. Connector 2px
  3. Label 14px under node
  4. Compact bar variant for mobile

Usage

  • 3–5 steps. Labels are nouns, ≤ 2 words.
  • Done steps are clickable to go back; upcoming are not.
  • Below 640px use the compact “Step 2 of 3” bar.

Accessibility

  • Ordered list; aria-current="step".
  • Done nodes include “completed” in visually hidden text.
  • State via icon/number/weight, not only colour.

Spec

<Steps current={2}
  steps={["The job","Photos","Your details"]}
  variant="full|compact"/>

Empty state

Stable

When a filter finds nothing or a shortlist is empty. Say what happened, offer the way out.

No exterior wallpaper projects

That combination doesn’t exist yet. Try one filter at a time.

Your shortlist is empty

Tap the star on any colour or project to save it here for your quote.

Browse colours

Anatomy

  1. Dashed plaster.300 frame, radius 12, 48px pad
  2. Icon 32 plaster.400
  3. H4 title, one-sentence body, one action

Usage

  • Title states the fact; body suggests the fix.
  • Never blame (“No results found for your query”).
  • No illustrations; the icon is enough.

Accessibility

  • Region role="status" so filter results announce.
  • Icon decorative.

Spec

<EmptyState icon title body
  action={{label, onClick|href}}/>

Tabs

Stable

Switch between related panels on one page: a project’s Photos / Colours / Details. Underline style, ochre indicator.

Panel content. 24px above; no border, the tab bar is the divider.

Anatomy

  1. Tab list, 1px plaster.200 baseline
  2. Tab 48px, 16px sides; selected = 600 weight + 2px ochre.400 inset underline
  3. Optional count, plaster.600
  4. Panel 24px below

Usage

  • 2–5 tabs; scrolls horizontally on mobile with fade edge.
  • Tabs change content, not URL. Page sections use nav links.
  • Don’t nest tabs.

Accessibility

  • ARIA tabs pattern: arrows move, Home/End, automatic activation.
  • Selected via weight + underline (not colour alone).
  • Focus ring inset so it doesn’t clip in the scroller.

Spec

<Tabs value onChange
  items={[{id,label,count,disabled}]}/>
indicator slides 150ms

Accordion

Stable

FAQs and “what’s included”. Native <details> under the hood; several can be open.

Do I need to move my furniture?
No. We move everything to the middle of the room, sheet it, and put it back at the end of each day. Large or fragile items (pianos, glass cabinets) we’ll discuss at the site visit.
How long does a room take?
One day for walls and ceiling in a standard room; add half a day for woodwork.
Which paints do you use?
Dulux Trade, Fleetwood, or Colourtrend as standard; Farrow & Ball and Little Greene on request. (Confirm with Errol.)

Anatomy

  1. Row ≥ 64px, 1px plaster.200 dividers
  2. Question H5-ish 18/600
  3. Chevron 20px rotates 180°
  4. Answer body, 24px bottom pad, 60ch

Usage

  • Questions as the client asks them. Answers ≤ 3 sentences.
  • First item open on FAQ pages.
  • Not for primary content; nothing important hidden.

Accessibility

  • Native <details>/<summary>: keyboard and screen-reader support for free.
  • Summary contains a heading (<h3>) for outline.
  • FAQPage structured data emitted from the same content.

Spec

<Accordion items={[{q,a}]}
  defaultOpen={[0]} multiple/>
chevron rotate 250ms · height auto

Pagination

Stable

For the portfolio grid past 12 items. Numbered on desktop, prev/next with a count on mobile.

1 2 3 … 8
PreviousPage 2 of 8Next

Anatomy

  1. 44px items, radius 8, 4px gap
  2. Current: ink.800 fill
  3. Ellipsis plaster.400
  4. Prev/next arrows

Usage

  • Show first, last, current ±1.
  • Prefer “Load more” only if the grid is under 3 pages.
  • Pages are real URLs (?page=2).

Accessibility

  • <nav aria-label="Pagination">; links labelled “Page 3”.
  • Disabled prev on page 1 is removed, not greyed.
  • Focus moves to the results heading after navigation.

Spec

<Pagination page={2} total={8}
  hrefFor={(n)=>`?page=${n}`}/>

Sticky CTA bar

Stable

Mobile only. Pinned to the bottom after the hero scrolls away: Call and Get a quote, always one thumb away. Principle 3 made physical.

page content scrolling
CallGet a quote

Anatomy

  1. Bar plaster.50 @98%, hairline top, soft up-shadow
  2. Call (secondary, flex 1) + Get a quote (primary, flex 1.4)
  3. Padding 12/16 + safe-area-inset-bottom

Usage

  • Below 768px only; appears after 400px scroll, slides 250ms.
  • Hidden on the quote form itself and when a Drawer/Modal is open.
  • Page gets 80px bottom padding so nothing is covered.

Accessibility

  • Rendered last in DOM inside a <nav aria-label="Quick actions">.
  • Doesn’t trap focus; reachable by tab order after the footer.
  • Respects env(safe-area-inset-bottom).

Spec

<StickyCta phone quoteHref
  showAfter={400}/>
position fixed · bottom 0 · z 40
display none ≥ 768px
