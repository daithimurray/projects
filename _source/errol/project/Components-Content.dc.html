Card

Stable

The base surface. White, 1px Plaster border, radius 12. Three variants by emphasis; interactive cards lift on hover.

Outlined · default
Border 1px plaster.200. Sits on plaster.50 or plaster.100.
Elevated
Shadow sm, no border. For cards over photos or dense grids.
Filled
plaster.50 fill on white pages. Quiet grouping.
Interactive · hover me
Whole card is one link. Lifts 2px, gains shadow md, border ink.200.
Inverse
Ink surface for the one highlighted item (e.g. recommended package).

Anatomy

  1. Surface, radius 12
  2. Optional media slot (top, full-bleed, radius inherits)
  3. Body padding 24 (compact 16, roomy 32)
  4. Optional footer row

Usage

  • Don’t nest cards. Use dividers inside.
  • Pick border or shadow, never both.
  • Max one inverse card per row.
  • Cards in a grid share height; content aligns top, footer bottom.

Accessibility

  • Interactive cards are a single <a>; no nested buttons (put them outside the link).
  • Card title is a heading at the correct level.
  • Hover lift is disabled under reduced motion.

Spec

<Card variant="outlined|elevated|
  filled|inverse" padding="md"
  interactive href="/…">…</Card>
radius 12 · border plaster.200
hover: translateY(-2px) shadow-md 150ms

Before / after compare

Stable

The signature component. A draggable divider over two aligned photos. Drag the handle.

{{ compare }}

Anatomy

  1. Container 4:3, radius 12, overflow hidden
  2. After photo (base), Before photo (clipped)
  3. Divider 2px white, handle 48px round with ‹ ›
  4. Labels “Before” / “After” in white chips

Usage

  • Photos from the identical spot. If they don’t align, use two Project cards instead.
  • Starts at 50%. No auto-animation.
  • One per viewport; it’s the hero of a case study.

Accessibility

  • Handle is <input type="range"> under the hood: arrow keys move 5%, Home/End snap.
  • Label: “Compare before and after. 50% before shown.”
  • Both photos have alt text; labels are visible text, not just position.

Spec

<Compare before={img} after={img}
  ratio="4/3" initial={50}
  labels={["Before","After"]}/>
handle 48 · divider 2px white
no easing while dragging

Testimonial

Stable

A real quote, a first name and area, the job, and where the review came from. Newsreader italic is reserved for this.

Anatomy

  1. Rating (optional), ochre.400
  2. Quote, Newsreader 400 italic 22/1.4
  3. Avatar 40 (initials), name + area, job · source · date

Usage

  • Quotes ≤ 40 words, verbatim. Trim with ellipsis, never rewrite.
  • Always name the source platform and month.
  • Inverse variant only for the single featured quote.

Accessibility

  • <figure> + <blockquote> + <figcaption>.
  • Stars have aria-label="5 out of 5 stars".
  • Italic at 22px passes; never italic below 18px.

Spec

<Testimonial quote name="Helen M."
  area="Bathwick" job="Hallway"
  source="Google" date="Mar 2026"
  rating={5} tone="light|inverse"/>

Badge

Stable

Static status label. Not clickable. Sentence case, 12px, caps only for the “eyebrow” tone.

Neutral Ink Most popular Available Oct 2 slots left Fully booked New Solid ink Outline With dot

Anatomy

  1. Container 4px 8px, radius 4
  2. Label 12px/600
  3. Optional 6px dot

Usage

  • Semantic tones only for real status (availability).
  • Ochre badge = one “Most popular” per pricing table.
  • Max 2 badges per card.

Accessibility

  • All tone text ≥ 4.5:1 on their tint (e.g. 1F5C38 on E6F3EB = 7.9:1).
  • Meaning in the words, not the colour.

Spec

<Badge tone="neutral|ink|accent|success|
  warning|error|info" variant="tint|
  solid|outline" dot>Available</Badge>

Tag / filter chip

Stable

Interactive pill for filtering the portfolio or showing selected options. Unlike Badge, it responds to taps.

Sage green 3 bedrooms

Anatomy

  1. Pill 36px, radius 999, 14px sides
  2. Selected: ink.800 fill + check
  3. Removable: ink.50 fill + 24px × button

Usage

  • Filter chips scroll horizontally on mobile; never wrap to 3+ rows.
  • Removable chips summarise a quote configuration.
  • “All” is always first and selected by default.

Accessibility

  • Filter chips: aria-pressed; result count announced via live region.
  • 36px chip gets 6px vertical hit-slop to reach 48.
  • Remove button names its chip.

Spec

<Chip selected onToggle>Interior</Chip>
<Chip onRemove>Sage green</Chip>
