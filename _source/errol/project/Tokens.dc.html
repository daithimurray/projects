Design tokens

Two layers. Base tokens are the raw palette and scales. Semantic tokens name a job (text.secondary) and alias a base value. Components only ever reference semantic tokens.

Developer guide

Framework-agnostic. The reference implementation is React + CSS custom properties, but every rule below holds in plain HTML, Astro, or a WordPress theme.

1 · Install

  1. Load fonts once in <head>: Newsreader 400i/500/600, Figtree 400/500/600/700, JetBrains Mono 400. font-display: swap; preload the two body weights.
  2. Generate tokens.css from tokens.json (Style Dictionary or a 20-line script). Never hand-edit the CSS.
  3. Global reset: box-sizing: border-box, body uses --font-body, --bg-page, --text-primary. Headings use --font-display.

2 · Component contract

  • Props in the spec blocks are the public API. Variant names are enums, never booleans (variant="secondary", not secondary).
  • Every component forwards className, ref, and native attributes; no wrapper divs around form controls.
  • Sizes: sm|md|lg → 40/48/56px. Default md.
  • Colour only via semantic tokens. A base token in a component file fails review.
  • No margins on components. Layout owns spacing via gap and padding.

3 · Accessibility gates

  • WCAG 2.2 AA. axe-core in CI with zero violations on every page template.
  • Keyboard walkthrough of the quote flow on every release.
  • :focus-visible ring on everything focusable: 2px --border-focus, offset 2px.
  • Targets ≥ 48px; visually smaller controls get pseudo-element hit-slop.
  • Every image has alt written by a human; decorative ones are alt="".
  • Reduced motion respected globally through duration tokens.

4 · Performance budget

  • LCP < 2.0s on 4G: hero photo AVIF/WebP, fetchpriority="high", sized with srcset at 640/960/1440.
  • CSS < 40 KB, JS < 60 KB gzipped for the marketing pages. Compare slider and quote flow are the only interactive islands.
  • Fonts ≤ 120 KB total, subset to Latin.
  • Portfolio images lazy-load below the fold at 4:3 with explicit width/height (no CLS).

5 · Responsive rules

  • Mobile first; breakpoints 640 / 768 / 1024 / 1280 as min-width queries.
  • Container: max-width: 1200px; padding-inline: var(--margin) where margin steps 16 → 24 → 32 → 48.
  • Grids use repeat(auto-fit, minmax(Xpx, 1fr)); only the page shell uses the explicit 12-column grid.
  • Type scales via clamp; no font-size media queries.
  • Tables → stacked cards, steppers → compact bar, navbar → drawer, all at 768.

6 · Content & SEO hooks

  • Structured data: LocalBusiness (footer), Service (service pages), FAQPage (accordion), BreadcrumbList, Review/AggregateRating (testimonials).
  • One h1 per page, from the Hero. Section headers are h2.
  • Phone via tel: with international format in href, local format in text.
  • Prices are text, not images; tabular numerals via font-variant-numeric.

Reference: Button in code

The pattern every component follows: semantic tokens, data-attributes for variants, native element underneath.

/* button.css */
.btn {
  display: inline-flex; align-items: center; justify-content: center; gap: var(--space-1);
  height: var(--control-md); padding-inline: var(--space-3);
  border-radius: var(--radius-2); border: 1px solid transparent;
  font: 600 1rem/1 var(--font-body);
  transition: background var(--dur-fast) var(--ease-out), border-color var(--dur-fast) var(--ease-out);
  cursor: pointer;
}
.btn[data-variant="primary"]   { background: var(--action-primary); color: #fff; }
.btn[data-variant="primary"]:hover  { background: var(--action-primary-hover); }
.btn[data-variant="primary"]:active { background: var(--action-primary-active); }
.btn[data-variant="secondary"] { background: var(--bg-surface); color: var(--action-primary); border-color: var(--border-strong); }
.btn[data-variant="ghost"]     { background: transparent; color: var(--text-link); padding-inline: var(--space-2); }
.btn[data-size="sm"] { height: var(--control-sm); padding-inline: var(--space-2); font-size: .875rem; }
.btn[data-size="lg"] { height: var(--control-lg); padding-inline: var(--space-4); font-size: 1.125rem; }
.btn:focus-visible { outline: 2px solid var(--border-focus); outline-offset: 2px; }
.btn[aria-disabled="true"] { background: var(--action-disabled-bg); color: var(--action-disabled-text); cursor: not-allowed; }
[data-tone="inverse"] .btn[data-variant="primary"] { background: var(--action-primary-on-inverse); color: var(--text-on-accent); }
